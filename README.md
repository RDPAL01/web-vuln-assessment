# Automated Web Vulnerability Assessment Framework

**Evidence-Aware Finding Correlation, Deduplication, Validation, and Risk Analysis**

An automated web vulnerability assessment framework designed to process, correlate, consolidate, and evaluate security findings generated by multiple vulnerability scanning tools.

## 1. Overview

Traditional web vulnerability scanners often report overlapping findings for the same underlying security issue. This can create duplicate alerts, inconsistent severity assessments, and additional manual analysis.

This project aims to address these challenges through a structured finding-processing pipeline.

The framework parses findings from OWASP ZAP and Nuclei, converts them into a common finding representation, analyzes relationships between findings, consolidates related findings, evaluates supporting evidence, and generates structured security reports.

The primary focus is evidence-aware finding correlation rather than simply combining scanner output.

## 2. Project Objectives

- Parse vulnerability findings from multiple security scanners.
- Normalize findings into a common data structure.
- Identify relationships between findings using endpoint, vulnerability name, security concepts, and evidence.
- Detect and consolidate duplicate or related findings.
- Evaluate evidence quality and scanner confidence.
- Calculate confidence and risk scores.
- Generate structured JSON, CSV, and HTML reports.
- Evaluate consolidated findings using available assessment outputs.

## 3. System Architecture

The current implementation consists of the following logical stages:

1. **Input Processing:** Read vulnerability scan outputs from OWASP ZAP and Nuclei.
2. **Finding Normalization:** Convert scanner-specific results into a common `Finding` representation.
3. **Correlation Analysis:** Compare endpoints, security concepts, evidence, methods, and scanner agreement.
4. **Deduplication:** Group related findings and consolidate them into representative findings.
5. **Validation and Risk Analysis:** Evaluate evidence, confidence, validation status, and risk.
6. **Report Generation:** Produce structured reports in JSON, CSV, and HTML formats.
7. **Evaluation:** Analyze generated reports and evaluation outputs.

## 7. Evidence-Aware Finding Correlation

The correlation engine analyzes multiple dimensions of vulnerability findings, including:

- Endpoint similarity
- Vulnerability name similarity
- Security concept similarity
- Evidence similarity
- HTTP method similarity
- Scanner agreement

The third correlation engine (`correlation_engine_v3.py`) includes functions for extracting concrete evidence, calculating similarity metrics, and classifying finding relationships.

The objective is to distinguish findings that represent the same underlying security issue from findings that are merely similar.

## 8. Deduplication and Consolidation

The deduplication engine uses a Union-Find data structure to build groups of related findings.

It includes functionality for:

- Building finding indexes
- Selecting primary findings
- Constructing relationship groups
- Determining group types
- Consolidating findings
- Calculating finding reduction statistics

This approach aims to reduce redundant vulnerability reports while retaining useful information from related findings.

## 9. Validation and Risk Analysis

The validation engine includes functionality for:

- Evidence scoring
- Scanner confidence analysis
- Correlation-based confidence bonuses
- Validation status determination
- Confidence score calculation
- Risk score calculation
- Risk-level classification

The framework is intended to support more informed vulnerability assessment by considering evidence and relationships between scanner findings.

## 10. Reporting

The report generator supports:

- JSON reports
- CSV reports
- HTML reports
- Finding statistics
- Structured vulnerability information

Generated outputs are stored locally in the `reports/` directory.

## 12. Installation

### Prerequisites

- Python 3
- Git
- OWASP ZAP
- Nuclei
- OWASP Benchmark (optional, for benchmark-related work)

### Clone the Repository

```bash
git clone --recurse-submodules https://github.com/RDPAL01/Automated-Web-Vulnerability-Assessment-with-Evidence-Aware-Finding-Correlation-and-Risk.git

cd Automated-Web-Vulnerability-Assessment-with-Evidence-Aware-Finding-Correlation-and-Risk
```

If the repository was cloned without submodules:

```bash
git submodule update --init --recursive
```

### Python Environment

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows:

```powershell
.venv\Scripts\Activate.ps1
```

Activate it on Linux:

```bash
source .venv/bin/activate
```

**Dependency note:** A dependency manifest is not currently included in the repository. Exact installation requirements and reproducible setup instructions remain to be documented.
